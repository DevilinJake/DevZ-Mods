Bigger loose-ammo stacks: one multiplier for everything, per-ammo overrides.

[list]
[*] Overrides only one value per ammo type ([b]count[/b]): no scripts, no performance cost.
[*] Weight per round doesn't change: a stack of 50 weighs the same as two of 25.
[/list]

[h2]Default settings[/h2]
[list]
[*] 2x stacks: 9x19 goes from 25 to 50, 12ga from 10 to 20, .22 from 50 to 100.
[*] Single-round items (rockets, 40mm grenades, darts) stay at 1.
[*] Loot: run [b]fix_loot.py[/b] from the GitHub repo once on your types.xml so the ammo found in the world stays the same size. Skip it if you want more ammo in the world.
[/list]
This Workshop build covers [b]vanilla items[/b], so it works on any server and needs no other mod. Running modded items? See below.

[h2]Server setup[/h2]
[list]
[*] Add it to [b]-mod=[/b] (players need it too; they download it automatically when they join).
[*] Copy [b]keys\DevZ.bikey[/b] from the mod folder into your server's [b]keys[/b] folder.
[/list]

[h2]Works with your other mods[/h2]
The mod comes with a [b]scanner[/b] that reads your server and every mod you run, and lists the ammo from any weapon mod in a simple table, next to the vanilla ones. Pick your own values for any of them (or keep the defaults), build it, and you have a copy made for your exact mod list.
[list]
[*] No programming: download the repo, run one command to scan, edit the table in Excel or Google Sheets, run one command to build.
[*] Step-by-step guide: [url=https://github.com/DevilinJake/DevZ-Mods/blob/main/CUSTOMISING.md]CUSTOMISING.md[/url]
[*] Then upload your copy to the Workshop (Unlisted is fine) or put it in your server pack, and use it instead of this one.
[/list]
