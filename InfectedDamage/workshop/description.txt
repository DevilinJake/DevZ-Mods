Zombies hit 1.5x harder out of the box, or build your own multipliers for Health, Blood, Shock, bleed chance and clothing wear (see below). Server-side only.

[list]
[*] One multiplier each, plus per-attack overrides (soldier, police, mummy zombies...).
[*] Config values only: no scripts, no performance cost.
[/list]

[h2]Default settings[/h2]
[list]
[*] Health 1.5x: 11 swipes kill a player with no armour (vanilla 16).
[*] Shock 1.5x: a group can knock you out with quick hits.
[*] Bleed chance 1.5x: 16.5% per hit (vanilla 11%).
[*] Blood and clothing wear unchanged.
[/list]
This Workshop build covers [b]vanilla items[/b], so it works on any server and needs no other mod. Running modded items? See below.

[h2]Server setup[/h2]
[list]
[*] Copy the mod folder into your server folder and add it to [b]-servermod=[/b] (not -mod=).
[*] Players don't download anything, and it needs no key.
[/list]

[h2]Your own settings and modded items[/h2]
The mod comes with a [b]scanner[/b] that reads your server and every mod you run, and lists the attacks of the zombies from any zombie mod in a simple table, next to the vanilla ones. Pick your own values for any of them (or keep the defaults), build it, and you have a copy made for your exact mod list.
[list]
[*] The settings are built into the mod, so this Workshop download only holds the finished mod. The tables, scanner and build script are on [url=https://github.com/DevilinJake/DevZ-Mods]GitHub[/url].
[*] No programming: download the repo, run one command to scan, edit the table in Excel or Google Sheets, run one command to build. You need Python and DayZ Tools (both free).
[*] Step-by-step guide: [url=https://github.com/DevilinJake/DevZ-Mods/blob/main/CUSTOMISING.md]CUSTOMISING.md[/url]
[*] Then load your copy with -servermod instead of this one (players still download nothing).
[/list]
