Weapons and suppressors wear out slower: one multiplier each, per-weapon overrides.

[list]
[*] Every shot wears a gun by the ammo's damageBarrel divided by the gun's [b]barrelArmor[/b]. This mod only raises barrelArmor, so 10x armor = 10x as many shots.
[*] No scripts, no performance cost. Safe to add to a live server.
[/list]

[h2]Default settings[/h2]
[list]
[*] Weapons last 10x as long.
[*] Suppressors and other muzzle attachments last 10x as long.
[/list]
This Workshop build covers [b]vanilla items[/b], so it works on any server and needs no other mod. Running modded items? See below.

[h2]Server setup[/h2]
[list]
[*] Add it to [b]-mod=[/b] (players need it too; they download it automatically when they join).
[*] Copy [b]keys\DevZ.bikey[/b] from the mod folder into your server's [b]keys[/b] folder.
[/list]

[h2]Works with your other mods[/h2]
The mod comes with a [b]scanner[/b] that reads your server and every mod you run, and lists the guns, suppressors and muzzle attachments from any weapon mod in a simple table, next to the vanilla ones. Pick your own values for any of them (or keep the defaults), build it, and you have a copy made for your exact mod list.
[list]
[*] No programming: download the repo, run one command to scan, edit the table in Excel or Google Sheets, run one command to build.
[*] Step-by-step guide: [url=https://github.com/DevilinJake/DevZ-Mods/blob/main/CUSTOMISING.md]CUSTOMISING.md[/url]
[*] Then upload your copy to the Workshop (Unlisted is fine) or put it in your server pack, and use it instead of this one.
[/list]
