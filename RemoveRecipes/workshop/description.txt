Switch off right-click crafting recipes from vanilla or any mod, without editing that mod.

[list]
[*] Handy when a mod has a shortcut recipe that skips its own crafting stations or rare ingredients.
[*] A scanner lists every right-click recipe in the game and your mods; tick the ones to remove.
[*] Bench/station recipes (e.g. Crafting Plus) live in those mods' own settings; this mod is for right-click recipes.
[/list]

[h2]Default settings[/h2]
[list]
[*] [b]None.[/b] This Workshop build removes nothing: it's a tool you customise for your server (see below).
[/list]
This Workshop build covers [b]vanilla items[/b], so it works on any server and needs no other mod. Running modded items? See below.

[h2]Server setup[/h2]
[list]
[*] Add it to [b]-mod=[/b] (players need it too; they download it automatically when they join).
[*] Copy [b]keys\DevZ.bikey[/b] from the mod folder into your server's [b]keys[/b] folder.
[/list]

[h2]Works with your other mods[/h2]
The mod comes with a [b]scanner[/b] that reads your server and every mod you run, and lists every right-click recipe from every mod you run in a simple table, next to the vanilla ones. Pick your own values for any of them (or keep the defaults), build it, and you have a copy made for your exact mod list.
[list]
[*] No programming: download the repo, run one command to scan, edit the table in Excel or Google Sheets, run one command to build.
[*] Step-by-step guide: [url=https://github.com/DevilinJake/DevZ-Mods/blob/main/CUSTOMISING.md]CUSTOMISING.md[/url]
[*] Then upload your copy to the Workshop (Unlisted is fine) or put it in your server pack, and use it instead of this one.
[/list]
